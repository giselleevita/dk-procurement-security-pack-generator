# DK Procurement Security Pack Generator — Pricing

## Context

Danish and Nordic public-sector procurement requires vendors to submit security documentation as part of tender bids. The alternative is hiring a GRC consultant at €5,000+/day to produce equivalent artifacts.

## Tiers

| Tier             | Price     | Includes                                                                                            | Target                                |
| ---------------- | --------- | --------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **Starter**      | €299/year | 10 security pack submissions, NIS2 control mapping, Markdown + PDF output                           | Solo vendors, freelance consultancies |
| **Professional** | €999/year | Unlimited submissions, ISO 27001 + NIS2 mapping, Ed25519 signature verification, priority templates | SMB software vendors (5–50 employees) |
| **Enterprise**   | Custom    | White-label, bulk API, multiple org units, custom framework mappings                                | Large vendors, GRC resellers          |

## Pricing Rationale

- A single tender submission typically requires 2–5 days of consultant time
- At €800–€1,200/day consulting rate, one submission costs €1,600–€6,000
- Starter tier recovers its cost after **one tender submission**
- Professional tier pays for itself after **one tender cycle**

## Distribution Channels

1. **Direct**: Danish landing page (da-DK) with free sample pack download
2. **Channel**: Nordic procurement software ecosystem partners (e.g., Mercell, TendSign)
3. **Public Sector**: Agreement with 1 Danish public-sector procurement portal for vendor onboarding
